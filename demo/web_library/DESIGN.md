# Quiet library v1

User steering: remove information overload and cheap raster collage. A still scene with blinking diodes is sufficient. All UI in English. Keep the implementation separate from Claude's work.

One deliberately composed illustration supplies the entire environment. The left side is quiet enough for real HTML typography; no wooden panels, parchment frames, separate character cutouts, artificial reel overlays, particles, camera motion or continuous character animation.

At first glance: project identity, one question, one action. Answer replaces the question view. Evidence is disclosed through a source dialog, with full passages one level deeper. Method and results are optional dialogs.

The generated artwork stays faithful to B00. Functional controls use restrained solid surfaces and plain rules, superseding the old “CSS draws nothing” constraint for this independent variant in response to the user's feedback. Typography: Alegreya for reading and headings, Grenze Gotisch only for the identity, Almendra for small labels. Walnut, warm parchment text, oxidized gold accents.

Three clipped copies of the exact background darken only indicator pixels intermittently, so lights remain aligned at every viewport size. Reduced-motion preference and manual pause disable the effect.

Recorded replay is explicitly identified. Answers and citations come verbatim from the saved Reactor run. Custom questions enter local retrieval first. No answer is synthesized in the frontend. Dev metrics never include unlabeled test records, and absent samples show no score.
